## 一、要做的是三套原作系统

| 原作 | 系统 | 核心循环 | 产出 |
|---|---|---|---|
| 《剑／盾》 | **宝可梦露营的咖喱饭** | 选食材 + 树果 → 生火、搅拌、看火候 → 评分 | 一锅咖喱，全队一起吃 |
| 《朱／紫》 | **野餐的三明治** | 面包 + 馅料 + 调味料 → 摆盘小游戏 | 带「食力」的一餐，效果持续一段时间 |
| 《传说 阿尔宙斯》 | **工艺制作** | 采集素材 → 工艺台 → 配方 | 精灵球、药、诱饵等消耗品 |

三者其实是**同一件事的三种皮**：拿材料 + 过一次手 → 出一个有数值的东西。
本作已经有对应的技能钩子，见下。

## 二、本作已有的接口（别重复造）

| 已有的东西 | 在哪 | 怎么接 |
|---|---|---|
| **工艺**技能 | `02-system-explained.md`「工艺」——原文就写了「绘画、雕刻、**烹饪**、修理」 | 烹饪和制作都走**工艺检定**，不用新技能 |
| **医术**技能 | 同上 | 配药走医术，别和工艺混（`itemprice.md` 的「自制药物」已经是这个口径） |
| 定制球的工艺先例 | `itemprice.md`「定制球（非卖品）」：备齐材料 + 工艺检定 | 制作系统的**现成模板**，照抄即可 |
| 食物 / 甜点 / 树果表 | `itemprice.md` | 食材来源；树果已经有「当持有物时自己吃」的规则 |
| **幸福度** | `02-system-explained.md` | 每点约需 10 份食物，可以和美容、甜点叠加 |
| 一次性 / 剂量 | `itemprice.md`「剂量怎么算」：1剂恢复1点伤害 | 烹饪产出也要落到这套点数上 |

**结论：不需要新技能，也不需要新货币。** 全部挂在工艺检定 + 幸福度 + 现有道具表上。

## 三、各自的转换思路（草案，未定稿）

### 3.1 咖喱饭（《剑／盾》）

原作三要素：**食材**（决定基础品质）、**树果**（决定味道与附加效果）、**火候评分**（决定成品等级）。

草案：

- 一次露营烹饪 = **一次工艺检定**，难度由「食材档次 + 人数」定。
- **树果**决定附加效果：用「能力果」就出对应的临时强化，用「抗性果」就出减伤，用「状态果」就出免疫。
  这套映射 `itemprice.md` 的补充树果已经分好组了，直接复用。
- **评分**：成功数越高，成品越好；大失败 = 糊锅（食材白费，全队幸福度-1）。
- 产出：**全队回血 + 幸福度 + 一顿饭的临时增益**（持续到下次长休）。

### 3.2 三明治（《朱／紫》）

原作的「食力」是遭遇率 / 捕获率 / 闪光率 / 经验值这类**电子游戏专属**的增益，本作没有对应概念，**必须换**。

草案：食力换成 TRPG 用得上的三档：

| 原作的食力 | 本作换成 |
|---|---|
| 遭遇力（更容易遇到某属性） | 野外探索时，指定属性宝可梦出现率提高（叙事者调整遭遇表） |
| 捕获力 | 接下来一场收服的**封印骰 +1** |
| 经验力 / 掉宝力 | 训练掷骰 +1 / 战利品多一份素材 |

持续时间：原作 30 分钟 → 本作**一个完整场景**（`02` 章的时间计量里正好有这一档）。

调味料（秘传调味料等）作为**稀有食材**，决定食力的强度与条数。

### 3.3 工艺制作（《传说 阿尔宙斯》）

这套最省事——**定制球已经是它的简化版**。要补的是：

- **素材表**：球果、玉石、蘑菇、骨头……需要从 52poke 抓一份「工艺素材」清单和配方。
- **配方即难度**：越高级的成品，工艺检定难度越高、需要的素材越稀有。
- **失败处理**：失败消耗素材但不产出（或产出一个残缺品）。

## 五、还没定的问题（开工前先拍板）

1. **咖喱和三明治要不要分开做两套？** 机制高度重合，也许合成一个「野炊」系统、
   用「锅 / 面包」两种器具区分就够，省得读者学两遍。
2. **烹饪要不要消耗游戏内时间？** `02` 章的时间计量有「完整场景」这一档，
   一顿饭算不算一个完整场景？
3. **食力的持续时间**用「一个完整场景」还是「到下次长休」？
4. **工艺制作的成品范围**：只做原书已有的道具（球、药），还是允许玩家自创？
   自创的话需要一套「素材 → 效果」的折算口径，类似补充球那套 4 颗骰 = 1×。
5. **和 `itemprice.md` 的关系**：烹饪产出是另开一页（`cooking.md`），
   还是塞进 `itemprice.md`？考虑到 `itemprice.md` 已经 700 多行、270 个图标，
   **建议另开一页**，`itemprice.md` 只留食材的价格。
