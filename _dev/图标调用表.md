# 图标调用表

从原书各册提取的图标清单。翻译时按这张表取用。

生成脚本：`_dev/extract_ball_icons.py`、`extract_move_icons.py` 等；新增图标后请同步 `assets/theme.css` 里的类名映射。

---

## 怎么用

**短标签 `<poke-icon>`（推荐）** —— 类名映射到背景图，标记里不用写 src / width / height / alt：

```html
<poke-icon class="mv powder"></poke-icon>
<poke-icon class="cat physical"></poke-icon>
<poke-icon class="tgt foe"></poke-icon>
<poke-icon class="mv reaction lg"></poke-icon>   <!-- lg = 图例大号 -->
```

类名规则：文件 `mv-powder.webp` → `class="mv powder"`。加 `lg` 放大到 2.6em。

**需要 alt 的场合**用 `<img>`：

```html
<img class="mv-icon" src="assets/img/mv-powder.webp" alt="粉末类招式" width="20" height="20">
```

**参数化徽章用 `<icon-frame>`**（数值会变的那些）。内部全部用 `em`，
改 `font-size` 就能整体缩放——速查页的表格里就用 `font-size: 0.8rem` 压小过：

```html
<icon-frame class="flinch"><b>畏缩</b><span>3</span></icon-frame>
<icon-frame class="accuracy"><b>命中</b><span>↓2</span></icon-frame>
<icon-frame class="reaction"><b>反应</b><span>↑1</span></icon-frame>
<icon-frame class="power"><b>威力</b><span>3</span></icon-frame>          <!-- 招式卡上的威力值 -->
<icon-frame class="power boost physical"><b>威力</b><span>+3</span></icon-frame>   <!-- 物理威力提升 -->
<icon-frame class="power boost special"><b>威力</b><span>+3</span></icon-frame>    <!-- 特殊威力提升 -->
<icon-frame class="burn"><b>灼伤1</b><span class="always"></span></icon-frame>     <!-- 勾 -->
<icon-frame class="burn"><b>灼伤1</b><span class="never"></span></icon-frame>      <!-- 叉 -->
```

**标题一律写中文**（反应 / 威力 / 灼伤），不要留英文。

威力徽章有两种形态，别混用：招式卡上的威力值**没有白色小框**（数值直接写在面板上），
道具给的威力提升**有白色小框**，且红＝物理、蓝＝特殊——颜色本身承载信息，不能只加个加号了事。

常用变体：`reaction`（反应，青底白框，内容写 `↑1` / `↓2`）、`power`（威力，灰底青边，数值直接写在底上）、
`flinch` / `burn` / `poison` / `frozen` / `confuse` / `paralysis` / `love`（状态异常）、
`buff` / `debuff` / `damage` / `accuracy` / `heal` / `target` / `self` / `priority`。

底色由 class 决定，
`<b>` 是顶部标题，`<span>` 是白框里的数值。**命中徽章是黑底 + 红块**，别写成整块红。

## 组件替代：这些位图别再用

原书有一类徽章是「框 + 标题 + 内容槽」结构，标题印死了英文、内容还会变。
这类已经全部转成组件，对应的位图**保留但不再使用**（留作对照原书）。

| 原来的位图 | 改用 |
|---|---|
| `st-love` / `st-burn1` / `st-paralysis` / `st-confuse` / `st-frozen` | `<icon-frame class="love｜burn｜paralysis｜confuse｜frozen"><b>着迷</b><span>3</span></icon-frame>` |
| `bf-no-evasion` / `bf-no-evasion-clash` / `bf-no-items` / `bf-change-type` | `<span class="field-chip">不可闪避</span>` |
| `mv-set-damage` | `<icon-frame class="damage"><b>伤害</b><span>X</span></icon-frame>` |
| `mv-reaction` / `mv-late-reaction` | `<icon-frame class="reaction"><b>反应</b><span>↑1</span></icon-frame>` |
| `.pw`（CSS 组件） | `<icon-frame class="power"><b>威力</b><span>3</span></icon-frame>` |

还留着的位图只有 `mv-recoil`（内容是插画，没有文字）——那个可以放心用。

**判断标准**：图标里如果有文字或数字，就该做组件；纯图形才做位图。

## 九、道具图标（原书 p.116–129）

道具册每张价目表的行首都有小图标，一共 **84 枚**，对应 `itemprice.md` 的 84 个道具行。
精灵球那几张表不在这里 —— 它们复用第八节的 `ball-*`。

命名规则：`item-<英文名 slug>.webp`（`Pokédex` → `pokedex`，`MooMoo Milk` → `moomoo-milk`）。
素材是矢量图，透明底，96×96 画布、内容统一缩到 84px，所以宽高比差异大的
（防狼喷雾 6×20pt、露营炉具 28×21pt）放在同一个方框里也不会一大一小。

写进表格用：

```html
| <img class="item-icon" width="18" height="18" src="assets/img/item-antidote.webp" alt="解毒药">解毒药 Antidote | 100 | …… |
```

`.item-icon` 是 1.5em 的方框（原书里道具图标约为字高的 1.6 倍，精灵球只有 1.13 倍，
所以比 `.ball-icon` 大一号）。**持有物那两张表原书就没有图标**，别自己找图补。

## 重新生成

```bash
python _dev/extract_move_icons.py          # 招式/场地图标（招式简介 p.436–439）
python _dev/extract_ball_icons_items.py    # 精灵球（道具册 p.122）
python _dev/extract_item_icons.py          # 道具图标（道具册 p.116–129），加 --montage 出拼版
python _dev/apply_item_icons.py            # 把道具图标写进 itemprice.md，加 --dry 只打印
```

**精灵球三个坑**：

1. **别用圆蒙版**：`extract_ball_icons.py` 那套正圆蒙版是给「捕捉」册的球用的
（那些球摆在彩色表格里）。道具册的球画在浅灰行底上，圆蒙版会把旧式球顶上的旋钮切掉。
2. **尺寸要按「固定裁切框」统一**：各球按外接框各自缩放会让大师球（两侧有凸起）、
   旧式球（顶上有旋钮）的球体变小。改成所有球都用同一个 32×32pt 的框套住圆心。
3. **黑暗球源文件是坏的**：p.122 上那枚右边缘是条直线，球被裁掉一块，只能镜像左半边补回来。

**技术要点**：图标都画在整页纸纹位图上。先把那张背景图换成 1×1 透明 PNG，
再 `get_pixmap(alpha=True)` 渲染，图标就自带透明底——不用泛洪去底，边缘保持矢量原样。
