## 四、四个关键决策（别推翻）

### 1. 标题级别：跟 PDF 的字号走，不跟 docx

用 PyMuPDF 扫过全章标题的 font-size：

| 字号 | 出现在 | 页面对应 |
|---|---|---|
| 50pt | 章节名 | H1 |
| **20pt（无方块）** | 大节 + 每张天气卡／环境卡 + 异常状态 | **H2** |
| **16pt（带方块）** | 伤害类型、STAB、额外伤害骰… | **H3** |

docx 里 异常状态 是 H3、天气卡 H4、环境卡 H5——那是把「卡片嵌套」当成了层级，
和 PDF 的字号对不上。页面按字号走。

> 如果照 docx 改：异常状态会变成「追加效果」的子项并带方块（和原书不符），
> 天气卡／环境卡会掉出右侧目录（H4 只在有活跃 H3 时才展开，H5 根本不进目录）。

### 2. 相克表不再重做，指到 `typechart.md`

原书 p.53 是一张静态大表。站内的 `typechart.md` 已经是可点的交互表，
第四章只放一张 `.link-card` 指过去。**别在正文里重排相克关系。**

### 3. 「第 XX 页」一律换成站内锚点

16 处引用都改成了 `#/02-system-explained?id=意志值wp` 这种。
只剩两处指向未上线的第九、十章（招式 434 页、特性 534 页），页面上写明了「尚未上线」。

改完用脚本对着两个页面的 DOM id 全量校验，**别手点**。

### 4. 卡片配色是纯色，不是渐变

原书这几类卡**全是纯色**。逐段扫色得到：

| 位置 | 色值 |
|---|---|
| 状态卡 抬头／色带 | 同一个色（不压深） |
| 状态卡 风味条 | `#f0f1f1` |
| 状态卡 正文（第一段／第二段） | `#c6c8ca` / `#b1b3b5` |
| 天气卡 描述条／条目区 | `#dbdcde` / `#c6c8ca` |
| 环境卡 正文 | `#dbdcde` |
| 冲抵&闪避 绿卡 | `#6dc49a` |

之前试过给抬头加渐变、色带 `color-mix` 压深，同一张卡出现三种色阶，看着发飘。

### 抠图四条经验

1. **插画是矢量的，纸纹才是位图。** 换掉整页纸纹图 + `get_pixmap(alpha=True)`
   就能拿到透明底，不用泛洪。
2. **英文说明也是矢量，会一起进画面。** clip 必须框在文字之外，宁可切窄一点。
3. **压在彩色底上的图用「颜色键控」而不是四角泛洪。**
   冲抵/闪避的插图压在绿卡上，泛洪会漏；用 `key_color(#6dc49a)` 一次清干净。
4. **同一个 doc 里一页只能 `replace_image` 一次。** 换完再找「最大图」会找到那张
   1×1，除零报错。所以每次渲染都重开文档。

> 页脚插图（p.60/61）的页码方块：**取样旁边的像素填色**，比清成透明安全——
> p.60 的页码压在纸上，p.61 的压在楼上，清透明会在楼上留个洞。

## 六、跟 docx 的差异（都是有意改的）

### 修掉的错字／错译

| docx | 页面 |
|---|---|
| 步骤六「多重行动的**第一次**行动，需要 2 成功」 | 第二次（原书 2nd Action） |
| 「它能**欧**无视防御」 | 能够 |
| 「**痛觉**惩罚」 | 伤痛惩罚 |
| 「**聪慧**+医术」 | 聪明 + 医术 |
| 「**冲使用**宝可梦招式」 | 冲抵用 |
| 「治愈道具与招式**轮**」 | 每轮 |
| 「第 1 **回合**使用护盾」 | 第 1 轮 |
| 「**核心规则**」（反应那节） | **注意事项**（原书 Things to keep in mind） |
| 步骤 3 / 6（阿拉伯数字） | 步骤三 / 步骤六 |

### 补回的内容

- **2 级灼伤的治疗成功数**：docx 中文写 6、英文写 4，**书上是 6**，取 6。
- **3 级灼伤**补回漏掉的「之后每轮伤害值增加 2 点」。
- **掩护表**中间一列 docx 是空的（文本层丢了），回 p.72 补上 +1 / +2 / +3。
- 三处占位符：「恢复等同于 ␣」「大竺葵剩余 ␣」「详见第 ␣ 页」。

### 自己加的（可删）

- **状态异常向导**：docx 标了「（略）」，用卡片里的数据压成一张速查表，页面上写明了。
- **属性相克表**：原书是图，这里换成外链（见决策 2）。
