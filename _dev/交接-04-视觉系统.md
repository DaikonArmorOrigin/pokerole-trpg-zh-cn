# 交接 04 · 视觉系统（纸感主题）

> 这一份讲**网页长什么样、为什么这么长**。
> 2026-10-28 做过一次整体改版：从「白卡片 + 红标题」换成「原书纸感 + 章节主色」。
> 改版后的所有色值都是从 PDF 上采样来的，不是凭感觉调的。

---

## 一、一句话概括

**一张奶油色的纸，压在更深的桌面上。**
每章有一条自己的主色带，章头色带、小节方块、点状分隔线、表头、列表圆点
全部用这一个颜色；正文用原书的墨色，插图直接"印"在纸上。

## 二、颜色从哪来

全部在 `assets/theme.css` 的 `:root` 里，改色只改这一处。

| 变量 | 值 | 出处 |
|---|---|---|
| `--paper` | `#f0ede1` | 原书纸底 `#e7e6db`，屏幕提亮一档 |
| `--paper-tint` | `#e9e5d6` | 纸面深一档：卡片、表头、凹槽 |
| `--paper-deep` | `#ddd8c7` | 再深一档：侧栏、内嵌槽 |
| `--paper-desk` | `#d8d3c2` | 纸外的"桌面" |
| `--paper-line` | `#cfc9b6` | 纸上的分隔线 |
| `--ink` | `#404042` | 正文墨色，**PDF 实测值** |

### 章节主色（`--ch-00` … `--ch-13`）

原书目录里每章一条色带，这里原样搬过来：

| 章 | 色 | 章 | 色 |
|---|---|---|---|
| 00 引言 | `#8d9092` 灰 | 07 旅途道具 | `#e8749f` 粉 |
| 01 世界 | `#da473e` 红 | 08 图鉴 | `#be3735` 深红 |
| 02 系统 | `#2899c1` 青 | 09 招式 | `#7c8b96` 石板灰 |
| 03 角色 | `#e8962f` 橙 | 10 特性 | `#7b6fc4` 紫 |
| 04 对战 | `#4fae7a` 绿 | 11 主持人 | `#a9713f` 棕 |
| 05 收服 | `#f4823a` 橙红 | 12 冠军之魂 | `#d4a017` 金 |
| 06 训练 | `#3f8fd2` 蓝 | 13 终章 | `#6b7a8a` 灰蓝 |

橙、金、绿这几个浅色在 PDF 里是配白字的，网页上对比度不够，
所以压深了一点点（`#fbaf3f` → `#e8962f`）。**别改回原值**，白字会糊。

## 三、章节色是怎么切过去的

`app.js` 里 `applyChapterTheme(path)`：

1. 从路由前两位取章号（`02-system-explained` → `02`）；
2. 给 `<body>` 挂 `data-chapter="02"`；
3. `theme.css` 里 `body[data-chapter="02"] { --ch: var(--ch-02); }` 把章号映射成颜色。

**新增章节不用改 app.js**，只要 `--ch-14` 存在、侧栏文件名是 `14-xxx.md` 就自动生效
（超出 13 的话记得在 `:root` 补一条变量和一条 `body[data-chapter="14"]`）。

速查页（`dice` / `typechart` / `itemprice` / `icons`）没有章号，
属性会被清掉，回落到 `--ch-00` 的灰色 —— 这是有意的，别给它们配色。

### 派生色必须写在 body 上

```css
body {
    --ch-deep: color-mix(in srgb, var(--ch) 76%, #000);   /* 色带下缘、表头、强调字 */
    --ch-wash: color-mix(in srgb, var(--ch) 11%, var(--paper));  /* 卡片底、高亮行 */
}
```

自定义属性按「继承到的计算值」传递：写在 `:root` 里会锁死在 `--ch-00` 上，
换章不跟着变。**这条踩过一次，别再挪回 `:root`。**

## 四、留白与"出血"

正文左右留白只有一个开关：

```css
.markdown-section { --pad-x: 34px; padding: 0 var(--pad-x) 60px !important; }
```

- 手机上 `--pad-x: 18px`（`@media (max-width: 640px)`）。
- 章头色带和页脚插画用 `margin: 0 calc(-1 * var(--pad-x))` 吃掉这个 padding，
  横贯整张纸 —— 这就是"出血"。
- **不要改成「子元素统一 margin」的写法**。`vue.css` 里有
  `.markdown-section p { margin: 1em 0 }` 这种 (0,1,1) 的简写规则，
  会盖掉 (0,1,0) 的 `>*`，结果是正文顶着纸边走。这是第二个坑。

## 五、标题的四个记号

原书每层标题都有固定记号，网页照抄：

| 层级 | 记号 | 实现 |
|---|---|---|
| H1 | 整幅章节色带 + 白字 + 深色下缘 | `background: var(--ch)` + `box-shadow: 0 5px 0 var(--ch-deep)` |
| H2 | 章节色文字，上面一排**圆点** | `h2::before` 用 `radial-gradient` 平铺，`background-size: 13px 7px` |
| H3 | 章节色小方块 + 深墨色粗体 | `h3::before` 一个 `0.82em` 的方块 |
| H4 | 深墨色粗体 + 下划线 | `border-bottom: 2px solid` |

**H1 后面的第一个 H2 不画圆点线**（`.markdown-section h1 + h2::before { display: none }`），
色带下面已经够重了。

### 标题里的图标为什么要垫白牌

`# <img class="title-icon">标题` 里的图标是彩色的（红球放在红带上直接糊成一片）。
`.markdown-section h1 .title-icon` 给了一块白色圆底 + 细阴影，
效果和原书里带白描边的球一样。

### docsify 会把标题包进 `<a class="anchor">`

```html
<h1 id="系统详解"><a class="anchor"><span><img class="title-icon">系统详解</span></a></h1>
```

所以：

- 正文链接的样式必须写成 `a:not(.anchor)`，否则链接色会顶掉标题色
  （症状：色带上的白字变成深色，看起来像没生效）；
- 色带里的 flex 布局要下放到 `.markdown-section h1 .anchor` 上，
  不然图标和标题各按各的基线摆。

## 六、卡片：实心圆角块，没有竖条

原书的旁注一律是**实心圆角块**，没有描边、没有左侧竖条。四类卡片统一成这个规则：

| 类 | 底色 | 标签 |
|---|---|---|
| `.tip-card` | 章节色 11% 混纸 | `--ch-deep` 药丸 |
| `.rule-card` | `#f5e5c3` 暖纸 | `#9a5a12` 药丸 |
| `.storyteller-note` | `#ddd9cc` 中性灰 | `#6e6e66` 药丸 |
| `.trainer-tip` | `#cb4236` 13% 混纸 | `#cb4236` 药丸（原书就是红色，别改回绿） |

标签是 `display: inline-block` + `border-radius: 999px`。

> **训练家贴士是红色系的**，色值从《3.0介绍+世界观》p.14 采样（圆标 `#cb4236`）。
> 曾经做成过淡绿，和原书对不上。它不跟章节色走——原书里不管哪一章，这张卡片都是红的。
**没有标题时 `.tip-title:empty` 会自动隐藏**，不留空行。

## 七、表格

原书表格没有竖线，只有隔行的浅色底：

- `th`：章节色实心 + 白字 + 上两角切圆；
- `td`：只留 `border-bottom: 1px solid var(--paper-line)`；
- 奇行 `--paper-tint` 55% 混透明，偶行透明。

**`vue.css` 的 `tr:nth-child(2n) { background: #f8f8f8 }` 和 `tr { border-top: 1px solid #ccc }`
必须显式盖掉**，否则在新纸底上会亮成一条条白带。已写在表格段里，别删。

## 八、页脚插画（scene-*）

原书几乎每页底部都压着一条横向场景插画，是全书最显眼的装饰。
网页上是**每章结尾一张**：正文读到底，正好收在一幅小景上。

| 文件 | 出处 | 用在哪 |
|---|---|---|
| `scene-market.webp` | 世界观册 p.14 | 00 引言（友好商店 · 宝可梦中心） |
| `scene-autumn.webp` | 世界观册 p.11 | 01 世界（秋日林道） |
| `scene-forest.webp` | 角色册 p.41 | 02 系统（双大树 + 皮卡丘） |
| `scene-town.webp` | 角色册 p.40 | 03 角色创建（大木研究所） |

生成脚本：`_dev/extract_scene_art.py`。三步：按页高比例裁 → 四角泛洪去底 →
抹掉页脚角上的印刷页码（**按行做左右邻居插值**，直接抠透明会在建筑底座上留个白洞）。

`app.js` 的 `CHAPTER_SCENES` 表决定哪章用哪张，没有登记的章就不放。

## 八之二、底色必须铺在 html / body 上

`vue.css` 里 `.content` 是 `position: absolute; top: 0; bottom: 0`，
**高度锁死在一屏**。把桌面色铺在它身上，页面往下滚之后它就够不到了，
底下露出 `body` 的白底（症状：往下拉一点，纸外面全变白，只有最上面一小条是纸色）。

正确做法是 `html, body { background-color: var(--paper-desk) }`，`.content` 保持透明。
html 的背景会被浏览器传播到整个画布，滚多长都铺满。

> 只写 `html` 有时不够（docsify 的 body 有 `height: 100%`），
> **两个都写上最稳**。这是实测出来的，不是保险起见。

打印样式里要把两者都还原成白色，否则打印预览会带一层米色底。

## 九、其它被一起改掉的地方

- **顶栏**从饱和红换成深墨 `#2d2e30` + 一道红底边。原因是每章都有一条彩色色带，
  顶栏再抢红/橙会和章节色打架。红色只留在精灵球和底边。
- **侧栏**换成纸色 `--paper-deep`，当前章的高亮直接用 `--ch` ——
  翻到哪一章，目录里那一条就自动染上那一章的颜色。
- **翻页按钮 / 页脚**在纸外的桌面上，配色跟着换成暖灰。
- **计算器 / 补盲图 / 掷骰器**（`.type-dual` `.team-chart` `.dice-roller`）
  原来是白底，改成「比纸面深一档」的凹槽色。原书里的表格框、示例框都是这个思路——
  不是提亮，而是压深。
- **打印样式**单独处理：色带改成黑字 + 黑下划线（省墨），页脚插画不打印。

## 十一、还原层（2026-10-29 · v3）

> 上一版把「纸感 + 章节色」的骨架搭好了；这一版做的是**把原书的具体排版搬过来**。
> 一句话原则：**能照着原书排的就别自己发明**，色值一律回 PDF 采。

### 11.1 为什么不改正文

这一批组件全部靠 `app.js` 在渲染后「挂类名 / 搬结构」，正文 `.md` 保持能直接读的写法：

| 函数 | 干什么 | 触发条件 |
|---|---|---|
| `markSkillTables()` | `\|点数\|效果\|` 的表 → 胶囊点数条 | 首列表头是「点数」**且表里真有点数圆点** |
| `wrapRankSections()` | `### 新手级：2` 连同后面的内容 → 一张等级卡 | 三级标题以「入门级/新手级/…/冠军级」开头 |
| `wrapPanels()` | 每个 H2 连同后面的内容 → 一块速查面板 | 只在 H1 是「开团速查台」的页面 |
| `tintRegions()` | 地区小节标题染上世界地图上的地区色 | 标题文字匹配九个地区名 |
| `fitPortraitFigures()` | 竖版插图收窄到 460px | 图片高/宽 > 1.12 |

好处：改样式只动 CSS，不用回头改几十处标记；标题仍然是真标题，**右侧目录和锚点都不受影响**。

### 11.2 点数条（原书 p.22–24 / p.27）

原书那不是表格，是**一排胶囊**：左格 6 个圆点（实心=当前值，空心=上限），右格说明，隔行错色。

- 基础能力五条用**冷灰**（`#c7c8ca / #dcddde / #f1f1f2`，PDF 实测）；
- 社交能力五条**各一个色系**（p.24 采样）：
  强壮 `#f6ed4b` · 帅气 `#f7945f` · 美丽 `#7f8fc8` · 可爱 `#ee9ec5` · 聪明 `#73c16b`；
- 颜色靠 `table.is-pip[data-tone="…"]` 一组变量给，`data-tone` 由 JS 按最近的三级标题认。

> **圆点不是字符了。** 以前 `{{1/5}}` 画的是 `●` `○` 两个汉字字符，
> 不同字体的空心圆大小能差一倍。现在把字符涂成透明、只用它的盒子画圆
> （`.attribute-dots > span`），实心空心永远一样大。

### 11.3 等级卡（原书 p.30–31）

八级是**八张卡**：顶部一条色带 + 压在左端的等级球 + 右上角编号方块。
色带色取自 PDF：入门 `#a7a9ac`、新手 `#da473f`、正式 `#289ac2`、资深 `#fbb040`、
专家 `#6ec49b`、精英 `#8b5da7`、大师 `#414042`、冠军 `#29bdbc`。

**浅色带（入门/资深/专家/冠军）用深字**，深色带用白字 —— `--rk-ink` 在 `app.js` 的 `RANKS` 表里，
不是 CSS 自动算的，因为四个色带的对比度是逐个量过的。

> 两个坑：
> 1. 搬内容时**必须停在 H4**。冠军级后面紧跟一个「宝可梦的等级无法超过其训练家」
>    四级标题，只停在 H2/H3 的话它会连同后面几段一起被卷进卡片。
> 2. 等级球用真 `<img>`，**不要用 `::after` + `background: var(--rk-ball)`**。
>    自定义属性里的 `url()` 会按声明它的样式表（`theme.css`）解析，
>    结果变成 `assets/assets/img/…`，球是空的。

### 11.4 联盟规则集海报（原书 p.15）

`01` 章那个 `<details id="league-rules">` 从「白底 + 左右竖条」换成了原书的**灰色插页**：
深色抬头（联盟徽标 + 方格旗）+ 四条缎带小节标题（灰 / 近黑 / 青 `#396873` / 红 `#af3f3a`）
+ 深色方块项目符号 + 两栏排布。

- 缎带左端那个「燕尾」是 `clip-path: polygon(0 0, 100% 0, 100% 100%, 0 100%, 38% 50%)`；
- 抬头里的联盟徽标是 `assets/img/league-mark.webp`，`_dev/extract_system_art.py` 按**亮度键控**抠的
  （原图是浅灰线稿压深灰底，不能只做泛洪）；
- 这个 `<details>` 现在是 `open` 的 —— 海报本来就是给人看的一页。

### 11.5 骰面与骰池

`die-1` … `die-6` 是从 p.34「Rolling the Dice」抠的六颗骰子（斜放方块 + 白点），

### 11.8 开团速查台（`gm-screen.md`）

新开的一页，不是章节，是给叙事者的一屏挡板。**七块面板**：判定 / 伤害骰池 / 意志值 /
双防方案 / 等级 / 年龄 / 时间计量，每块一个颜色，扫一眼就能定位。

- 面板色借的是各章主色，**只当标签用**，页面整体仍然回落到灰色（速查页不给章节色的规矩没破）；
- **不重复已经译好的表。** 难度等级、多重行动的完整表格在 `dice.md`，速查台只放一句链接过去 ——
  第二版曾经把这两块重译了一遍，措辞和原稿对不上，还多加了一段自造的训练家贴士，已经删掉；
- 面板名一律用**正文里的译名**（等级、时间计量、多重行动），不要另起「等级阶梯」「时间单位」这种新词；
- 面板里的表格**不写死 `width: 100%`** —— 写死以后浏览器会把多出来的宽度平均分，
  「低 / 优秀」这种一两个字的列会空出一大片。用 `width: auto` + `max-width: 100%` 让它按内容分；
- 等级表是七列、横跨两栏，**唯独这一张**给 `width: 100%`，否则七列挤在左边一条、右边空一片。

### 11.9 踩过的坑（两轮反馈合并，按血泪排）

| 症状 | 真正的原因 |
|---|---|
| 搬内容时卡片里空了一大块 | **先 append 再取 `nextElementSibling` 永远是 null**。必须先收成数组再一次性搬（`wrapPanels`、`wrapNatureCards` 各踩一次） |
| 等级球是空的 | 自定义属性里的 `url()` 按声明它的样式表解析，`var(--rk-ball)` 变成 `assets/assets/img/…`。球要用真 `<img>` |
| 点数条在手机上文字顶出纸外 | `td:nth-child(2)` 被钉成定宽 —— 两列表里第 2 格就是说明格，要写 `:not(:last-child)` |
| 速查台「属性档位」表变成一排空胶囊 | 首列表头也叫「点数」，被 `markSkillTables()` 误认。判据要加「表里真有点数圆点」 |
| 面板标题的色块压在字上 | `h2::before` 原本是 `position:absolute` 的整行点线，改样式必须把 `position/inset` 复位 |
| 图例没排成网格 | `convertDots()` 会在外面套一层 `<span>`，`li > .attribute-dots` 选不到，要用 `li .attribute-dots` |
| 圆标里「叙事者笔记」断成 4+1 | 中文按容器硬断。加 `text-wrap: balance` → 3+2 |
| 点数条最后一行（6 点）左右都错开 | 点格是 `center`，5 点和 6 点居中位置不同。改 `flex-start`——**原书就是左对齐** |
| 白点看着比黑点小一号 | `inset` 描边从白盘里啃掉一圈。改成**外**描边 `0 0 0 1px` |
| 三列表中间那格没底色 | 底色只写在 `td:last-child`。要写在**所有 td** 上，再单独覆盖第一格 |
| 骰池里失败的骰子变蓝点 | `attr-available` 用了 `var(--ch)`。**红点 = 没成功的骰子**，写死 `#e3350d` |
| 「最初的伙伴」成了彩色精灵球 | 误用 `ball-poke`。原书 p.50 是**实心剪影球**，见 `icon-starter` |

> 三种球别混：`ball-*` 彩色球（道具/等级）、`ball-starter` 线稿球（05 章入门级）、
> `icon-starter` 实心剪影球（03 章「最初的伙伴」）。

### 12.4 踩过的坑

| 症状 | 原因 |
|---|---|
| 副题在色带上糊成一团 | 全局 `.markdown-section em` 会把字染成 `--ink-soft`，得用 `.sc-type em { color: inherit }` 顶回来 |
| 场地示意图里「主竞技区」被球压住 | 球原来用 `::after` 绝对定位压在正中，文字也在正中。改成 flex 竖排（球在上、字在下），球换成真 `<img>` |
| 抠出来的插画里混进英文 | 说明文字也是矢量，会和插画一起渲染。**clip 必须框在文字之外**，宁可切窄一点 |
| 想给插画去灰底，结果火焰被啃出洞 | 灰底和火焰高光是同一个色，泛洪会漏进去。**别去底**，直接连灰面板一起用 |
| 相克表在手机上表头被截断 | 表头写了「免疫（没有效果）」这种长标签。**表头只留两个字**，解释挪到表前的列表里 |
| 右侧目录会不会被 128 个标题撑爆 | 不会。`.page-toc` 只常驻 H2，H3/H4 跟着滚动位置逐级展开 |
| 两个「固定伤害」标题 | docsify 的锚点按标题文字生成，重名会撞。伤害骰池那节改叫「固定伤害池」 |
| 天气图标「方块压在圆上」 | `wx-*` 是圆角方块，原书是圆形。别垫白圆牌，直接摆上去，方块底色和色带同色系 |
| 头像里残留灰色块 | 头压在彩色方块上，四角泛洪够不着耳朵缝里的灰。改用**整片颜色键控**（`key_color`） |
| 天气图标顶出色带 | h3 只有 2.3rem 高，图标 2.3em 就溢出了。给 h3 加 `min-height: 3.2rem` |
| 反应图两个「结果」都做成深灰块 | 原书里结果格**不铺底色**，只把字染成对应角色的颜色（青＝皮卡丘、红＝伊布），头像照留 |
| 页脚插画带页码 | p.60 的页码压在纸上、p.61 压在楼上。按矩形取样旁边的像素填色，比清成透明安全 |
