## 〇、怎么用这份表

### 译名优先级

碰到一个词，按这个顺序找答案：

1. **本表已有的** —— 直接照抄，不要换词。
2. **宝可梦官方中文译名** —— 属性、地区、组织、性格、道具、宝可梦名，一律用官方简体译名

   （以 [52poke](https://wiki.52poke.com/) 为准）。
3. **本表没有、官方也没有** —— 先在本表「待定」区记下来，和组里确认后再统一，

   不要自己先译了再说。

### 三条硬规矩

- **同一个词只能有一种译法。** 前文「叙事者」后文「主持人」，读者会以为是两个角色。
- **机制词不做文学化改写。** 「意志值」就是「意志值」，不要为了行文流畅写成「意志力」

  「意志点数」——那会让读者以为是三种东西。
- **首次出现给英文原文。** 正文里第一次提到关键术语时写成「叙事者（Storyteller）」，

  之后只用中文。这样读者能对上英文原书。

### 大小写与标点

- 机制术语在正文里**不加粗**（加粗留给强调和卡片标题），但在本表和速查页里加粗。
- HP、WP、NPC、GM 这类缩写一律全大写，前后不加空格。
- 骰子写作「D6」，不写「d6」「D 6」。

### 卡片类型

原书用彩色方框做旁注，网页上对应五种 callout。**卡片名本身也是术语**，
  
翻译时按下面的对照写，不要自己起名。

| 中文        | 英文                   | 颜色  | 用途                 |
| --------- | -------------------- | --- | ------------------ |
| **叙事者笔记** | **Storyteller Note** | 灰   | 给叙事者的提示（原书 p.13 起） |
| **训练家贴士** | **Trainer Tips**     | 红   | 给玩家的提示（原书 p.14 起）  |

>

## 二、基础能力（Attributes）

原书 p.22–23。人类初始 1 点、上限 5 点；宝可梦因种类而异。

| 中文       | 英文          | 说明                                                                                   |
| -------- | ----------- | ------------------------------------------------------------------------------------ |
| **基础能力** | Attributes  | 也叫「属性值」，但「属性」已被 Type 占用，统一用「基础能力」                                                    |
| 力量       | Strength    |                                                                                      |
| 敏捷       | Dexterity   |                                                                                      |
| 耐力       | Vitality    | 影响 HP                                                                                |
| **特攻**   | **Special** | **只有宝可梦有**。原书是 Special，不是 Special Attack——它同时涵盖攻击与防御两端，译「特攻」是沿用宝可梦习惯，读者能接受；但不要写成「特殊」 |
| 洞察       | Insight     | 影响意志值                                                                                |
| **极限**   | **Limit**   | 能力/技能的**上限值**，专有词（02 章有专门一节解释）。**不要写成「上限」「最大值」**                                     |

> **易错**：`Special` 和 `Sp.Defense`（特防）是两个东西。
>
> 前者是能力项，后者是防御值。别都译成「特防」。
>
> 还要&#x548C;**「特殊招式」**&#x5206;开：招式分类是「物理／特殊／变化」，
>
> 这里的「特殊」是官方术语（Special Move），**不改**。
>
> 也就是说：能力项写「特攻」，招式类别写「特殊招式」，两者不是一回事。

| 中文   | 英文                     | 效果             |
| ---- | ---------------------- | -------------- |
| 忍痛前行 | Power through the Pain | 本场景内忽略伤痛惩罚     |

## 十二、易错点（踩过的坑）

| 错误写法        | 正确        | 原因                                      |

## 十三、已确认的译法（2026-10-29 组内定稿）
