# 欢迎来到宝可梦TRPG世界

这里是宝可梦TRPG（桌游）中文规则书的粉丝翻译计划。

> 本项目正在将 [PokeRole 规则书](https://hazmole.github.io/PokeRole/) 翻译成中文，让更多训练家能够一起享受在桌面上冒险的乐趣。

## 这是什么类型的游戏？

一款由2~6人参与的桌面角色扮演游戏。玩家扮演训练家，与自己的宝可梦伙伴一起进行冒险、对战斗、遭遇事件。

## 入门需要什么？

需要六面骰子（D6）若干个、铅笔与角色记录表，以及一本《规则书》与《宝可梦图鉴》。当然，还需要一个想像力丰富的GM。

## 如何使用本规则书

- 📖 左侧边栏列出全部章节，点击即可跳转。
- 📑 宽屏下右侧还有一列「本页目录」，直接跳到本章的任意小节。
- 🔍 点侧栏顶部的「搜索规则内容」，或右下角的图鉴按钮，可以搜全文；结果里是原文片段，点一下就跳过去。
- 🎲 「快速参考」里的 [快速掷骰](dice.md) 可以按骰池直接掷，自动数出成功骰。
- 🧾 同样是「快速参考」里的**角色卡**，可以在网页上直接填写训练家和宝可梦的资料，点右上角「保存为图片」就能导出一张 PNG 拿去打印或分享。
- 📱 在手机上，左上角菜单按钮可展开/收起侧边栏。
- 📴 联网打开过一次之后，整本书会存进浏览器，断网也能继续读。

点下面的「下一节」，或者从左侧导航选择 **引言** 开始你的冒险吧！
